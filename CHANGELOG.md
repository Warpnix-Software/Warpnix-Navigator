# Changelog

All notable changes to Warpnix Navigator are documented here.

## 2026.11.0

### Added

- Built-in ad and tracker blocker powered by WebKit content filters.
- Cosmetic filtering for leftover ad placeholders.
- Pop-up blocking.
- Editable custom blocklist in Settings.
- Migration Wizard for Firefox, LibreWolf, Waterfox, Chrome, Chromium, Brave, Edge, Vivaldi, and Opera.
- Netscape-format bookmarks HTML import.
- Bookmarks library with HTML export.
- Expanded search-engine catalogue with a standalone chooser window.
- Scrollable Settings window.
- GUI uninstaller with confirmation; settings and history are preserved.
- Haiku-style page-load error screen with a retry link.
- Oceanic Blue and Forest Night themes.
- About dialog using Zenity when available, with a GTK fallback.
- BSD support for FreeBSD, OpenBSD, NetBSD, and DragonFly BSD.
- Downloadable Linux and BSD release archives under `releases/`.

### Changed

- Address-bar searches now use proper URL encoding.
- User agent and About dialog now report the host platform.
- Missing logos no longer break desktop-entry creation.
- Installer version label updated to 2026.11.0.
